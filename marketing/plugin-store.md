Table Maker lets authors create the rows and columns their content needs within the boundaries configured for the field. Capture genuinely tabular information in Craft and render it with complete template control.

Authors can add and label columns and rows directly in the field, making the format useful for comparison tables, schedules, specifications, and other data whose dimensions vary between entries.

## Features

- **Typed columns:** Build tables with text, dropdown, date, checkbox, row-heading and other purpose-specific columns.
- **Column controls:** Reorder columns and configure their headings, widths, alignment and options in a focused editor.
- **Field boundaries:** Restrict available column types and set minimum or maximum row and column counts.
- **Flexible rows:** Grow or reduce the table to match the available information.
- **Efficient entry:** Paste data from a spreadsheet or insert a row exactly where it belongs.
- **Rich text:** Enable formatted cells when Craft’s CKEditor plugin is available.
- **Captions:** Add an optional caption to each stored table.
- **Direct cell editing:** Enter table values through a purpose-built Craft field.
- **Structured value:** Keep column settings, rows and cells available to Twig and GraphQL.
- **Flexible rendering:** Use the built-in HTML output or build accessible project-specific markup from the stored table value.
