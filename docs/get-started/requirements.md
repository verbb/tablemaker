# Requirements

## Craft CMS

Table Maker requires Craft CMS 5.6 or greater.

## PHP

Table Maker requires PHP 8.2 or greater.

## CKEditor

The optional **Rich text** column type requires CKEditor 5.0 or later, which in turn requires Craft CMS 5.9 or later. CKEditor must be installed and enabled before you can add rich-text columns. Existing rich-text content remains available as raw HTML if CKEditor is unavailable or an earlier version is installed.
